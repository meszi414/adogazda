# AdóGazda

Az adogazda.hu oldal forrása (React + Vite + Tailwind CSS), GitHub Pages-en hostolva.

## Parancsok

- `npm run dev` – fejlesztői szerver: http://localhost:3000
- `npm run build` – éles build a `dist/` mappába
- `npm run preview` – a kész build helyi kipróbálása
- `npm run deploy` – build és feltöltés a `gh-pages` ágra
